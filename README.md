# 4-session
Репрезиторий с материалами для подготовки к 4-й сессии 
Здесь хранятся материалы по 4 предметам, которые будут на сессии

## ТФКП
В папке **complan** содержатся файлы с теоретическими вопросами и ответами на них (.pdf и .tex). Также содержится файл с ответами от потока 2024 года (вопросы во многом совпадают).

## Алгебра
В папке **Algebra** содержатся файлы с теоретическими вопросами и ответами на них (.pdf и .tex), а также файл с исходными вопросами

## Теормех
В папка **theormech** содержатся файл с исходными вопросами, а также файл с ответами на них. Также есть файл с ответами от потока за 2024 год (вопросы во многом сопадают с 2026).

## Мзяпы
В папке **Asm** содержатся файл с вопросами для экзамена и файл с ответами на них от потока 2024 года (вопросы 2024 и 2026 совпадают)
